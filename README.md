# 抖音 PC 客户端「最高画质」一键补丁

让抖音电脑版**每条视频都按它能给的最高画质播放**：有 4K 源就播 4K（含 4K60），只有 2K/1080P 就播那一档，并且不会看着看着被悄悄降档。

> ⚠️ 仅供学习研究，请自行评估风险。

---

## 怎么用（30 秒）

1. **下载并解压**本仓库（右上角 `Code → Download ZIP`），或直接下 [最新 Release](https://github.com/hutaodog/douyin-4k-patch/releases/latest) 里的 `douyin-4k-patch-v1.1.zip`
2. 双击 **`一键开启4K.cmd`**
3. 按提示走完（如果抖音正在运行，它会帮你关掉并在打完补丁后重新打开）

打开抖音随便点个视频，右下角清晰度应显示「超清 4K」（或该视频的最高档）。

**还原**：双击 `恢复原版.cmd`。

### 之前装过旧版？

**直接用新版双击覆盖安装就行，不需要先卸载。**

安装器是幂等的：写入前先按标记把旧补丁整块剥掉再追加，所以不会叠加成两份；
旧版带的各种探针块也会一并清掉。备份文件 `preload.js.dypc4k.bak` 只在第一次安装时创建，
之后无论覆盖多少次都保持**官方原版**，所以「恢复原版」永远能还原到干净状态。

实测记录（先装旧版，再跑新版一键）：

```
旧版安装后   md5 83241ad5    补丁块 1 个   含标签修正 否
新版覆盖后   md5 7f4c3f4c    补丁块 1 个   含标签修正 是
备份文件     BFCB8E31（官方原版，未被覆盖）
注入后语法   node --check 通过
```

> 例外情况：如果 `.bak` 备份被手动删过，安装器会以"当前文件"为基准剥再写，
> 这时「恢复原版」只会还原到"带补丁的版本"——那种情况需要重装抖音客户端。

## 它做了什么

抖音客户端的 `preload.js` 在网页脚本之前执行。补丁在这文件末尾追加一段脚本，做四件事：

| # | 做什么 |
|---|---|
| 1 | 把 `sessionStorage['MANUAL_SWITCH']` 幂等写成 `{gearType:-2, gearClarity:'20', gearName:'超清 4K'}` |
| 2 | 改写服务端 AB 配置里的「自动降档 / 自动重选清晰度」开关 |
| 3 | 钉住编码族（h264），拦截 4K 档被客户端从列表里抽走 |
| 4 | 让客户端底部的清晰度标签跟上真实解码分辨率（纯文字，不碰播放逻辑） |

播放器自己会「够得着 4K 就 4K、够不着就取档位表里最高的那一档」，所以最终效果是**每条视频都是它的最高画质**。

补丁**不读 cookie、不联网、不上传任何东西**，只改抖音自己的一个文件，并在改之前备份成 `preload.js.dypc4k.bak`。

## 常见问题

**Q：之前装过旧版，要先卸载吗？**
A：不用。直接双击新版覆盖安装即可——安装器会剥掉旧补丁再写新的，备份也仍是官方原版（详见上面「之前装过旧版？」）。

**Q：提示找不到抖音客户端？**
A：装在特殊位置时，用 PowerShell 指定路径：

```powershell
powershell -ExecutionPolicy Bypass -File .\dypc4k.ps1 -Mode apply -InstallRoot "D:\你的路径\douyin"
```

**Q：有的视频还是 1080P / 720P？**
A：不是补丁失效。抖音给每条视频准备的档位不同（老视频、竖屏视频、转载视频常常只有 1080 甚至 720），补丁做的是「该视频最高档」，不会凭空造出 4K。

**Q：底部标签还写着 720P？**
A：补丁会按真实解码分辨率纠正它；以客户端统计面板里的「分辨率」为准。

**Q：抖音更新后画质掉了？**
A：更新会覆盖 `preload.js`，重新双击 `一键开启4K.cmd` 即可。

**Q：杀毒软件报警？**
A：因为它在修改另一个程序的文件，行为上容易被误判。代码全在这个仓库里，`preload-snippet.js` 可以逐行看。
